# Current state

Where2Go ranks dungeon or raid content by the share of eligible loot matching a character's useful saved preferred items. A character-scoped ownership toggle selects exact-item or usable same-slot exclusion using equipped gear and ordinary bags; saved preferences and the ordinary drop pool remain intact. Direct-drop and Voidcore views remain separate. Mythic raid direct drops use each boss's 1/6, 2/6, 3/6, or final-boss 9/6 level; Voidcore raid rewards use the equivalent Great Vault level, Myth 6/6 for bosses 1–6 and Myth 9/6 for the final two. The manifest targets Interface `120100` (Midnight Season 2).
